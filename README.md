# C++ Practice

A collection of my C++ implementations of data structures, graph algorithms, and competitive programming problems.

## Contents

### Data Structures and Graph Algorithms

This section contains implementations of fundamental graph representations and algorithms, including:

* Adjacency-list graph representation
* Dijkstra’s shortest-path algorithm
* Topological sorting
* Reverse graph construction

These exercises helped me practice implementing algorithms directly, selecting appropriate data structures, analyzing time complexity, and debugging traversal and edge-case errors.

### Competitive Programming

The repository also contains solutions to algorithmic problems from:

* USACO
* LeetCode
* Luogu

These problems cover topics such as graph traversal, searching, sorting, dynamic programming, and algorithmic optimization.
